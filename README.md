# PDF Translator with Gemini 3.5 Flash

اپلیکیشن ترجمه PDF با استفاده از Gemini 3.5 Flash که روی اندروید (Pydroid 3) اجرا می‌شود.

## ویژگی‌ها

✅ ترجمه PDF با حفظ ساختار
✅ خروجی HTML و PDF
✅ مدیریت چند کلید API
✅ محدودیت‌های API (500 درخواست/روز، 250k توکن/دقیقه، 10 درخواست/دقیقه)
✅ کار با Cloudflare Worker
✅ رابط کاربری زیبا (Kivy/KivyMD)
✅ نصب خودکار وابستگی‌ها

## نصب و راه‌اندازی

### 1. نصب وابستگی‌ها

برای نصب خودکار همه چیز:

```bash
python setup.py
```

### 2. راه‌اندازی اپلیکیشن

```bash
python app.py
```

### 3. تنظیمات اولیه

1. در صفحه تنظیمات، یک کلید API اضافه کنید
2. کلید پیش‌فرض را انتخاب کنید

## نحوه استفاده

### بارگذاری PDF
1. روی دکمه آپلود کلیک کنید
2. فایل PDF را انتخاب کنید
3. مسیر فایل را تایید کنید

### ترجمه PDF
1. روی دکمه "شروع ترجمه" کلیک کنید
2. در صورت تمایل، از Cloudflare Worker استفاده کنید
3. فرآیند ترجمه را مشاهده کنید

### تولید خروجی
1. ترجمه را کامل کنید
2. فرمت خروجی را انتخاب کنید (HTML یا PDF)
3. خروجی را دانلود کنید

## ساختار پروژه

```
my-app/
├── setup.py              # اسکریپت نصب خودکار
├── app.py                # برنامه اصلی با GUI
├── main.py               # نسخه خط فرمان
├── requirements.txt      # وابستگی‌ها
├── config.yaml           # تنظیمات
├── api_stats.json        # آمار API
├── cloudflare-worker.js  # ورکر کلادفلر
├── pdf_utils.py          # ابزارهای PDF
├── api_manager.py        # مدیریت API و کلیدها
├── translator.py         # لاجیک ترجمه
├── output_generator.py   # تولید خروجی
├── ui/                   # رابط کاربری
│   ├── main_screen.kv
│   ├── settings_screen.kv
│   └── progress_screen.kv
├── cache/                # کش ترجمه‌ها
├── temp/                 # فایل‌های موقت
├── outputs/              # خروجی‌ها
└── README.md             # راهنما
```

## محدودیت‌ها

- **۵۰۰ درخواست در روز**: برای هر کلید API
- **۲۵۰,۰۰۰ توکن ورودی در دقیقه**: برای هر کلید API
- **۱۰ درخواست در دقیقه**: برای هر کلید API

## فایل‌های مهم

### تنظیمات
- `config.yaml`: تنظیمات اصلی اپلیکیشن
- `api_stats.json`: آمار استفاده از API

### ابزارها
- `pdf_utils.py`: پردازش PDF
- `api_manager.py`: مدیریت API و کلیدها
- `translator.py`: لاجیک ترجمه
- `output_generator.py`: تولید خروجی

### رابط کاربری
- `app.py`: کلاس اصلی اپلیکیشن
- `ui/`: فایل‌های KV برای UI

## راه‌حل مشکلات

### خطای "کلید API یافت نشد"
- ابتدا یک کلید API اضافه کنید
- کلید پیش‌فرض را انتخاب کنید

### خطای "محدودیت روزانه رعایت شد"
- منتظر باشید تا روز بعد باشد
- یا از کلید دیگری استفاده کنید

### خطای "محدودیت نرخ درخواست رعایت شد"
- سیستم به صورت خودکار منتظر می‌ماند
- یا کلید دیگری را انتخاب کنید

## بهینه‌سازی‌ها

- **کش**: ترجمه‌های قبلی در کش ذخیره می‌شوند
- **پروکسی**: Cloudflare Worker برای دور زدن محدودیت‌های ایران
- **بخش‌بندی**: متن‌های طولانی به بخش‌های کوچک تقسیم می‌شوند
- **چند کلید**: امکان استفاده از چند کلید برای بالانسینگ

- Pydroid 3 (اپ پایتون برای اندروید)
- Android 8.0+
